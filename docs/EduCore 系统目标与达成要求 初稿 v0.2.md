**EduCore 系统目标与达成要求 初稿 v0.2**

**一、系统定位**

EduCore 是一个面向所有学生的平等学习与成长平台。系统不把学生按地域、家庭条件或资源多少贴标签，而是通过统一、公平、可验证的学习机会，减少因教育资源差异造成的成长差距。

它既是自适应学习平台，也是连接学生、家长、学校、教师与社会志愿资源的教育支持系统。长期目标是提升学生整体学习水平、考试适应能力、未来选择能力，并服务国家人才培养。

**二、核心愿景**

EduCore 希望给学生一个更平权的机会。

很多偏远地区或资源不足环境中的学生，并不是能力不足，而是机会不足：见过的题型少，练习方式少，对考试变化、行业环境、学校选择和专业选择的认知也有限。系统希望让所有学生都能接触更多题型、更完整的练习路径和更真实的社会经验，从而在考试、升学和未来职业选择中更容易适应。

系统不是“专门帮助某一类学生”，而是对所有学生一视同仁。它的重点是扩大公平机会、提升整体水平、发现和培养人才。

**三、服务对象**

EduCore 面向完整的教育与社会支持生态，包括：

1. 学生
2. 家长
3. 学生所在学校
4. 学校老师与管理者
5. 志愿者
6. 志愿机构
7. 志愿企业
8. 志愿老师
9. 志愿学校

系统需要让这些角色在清晰边界、可管理流程和可追踪证据下协同参与学生成长。

**四、系统目标**

1. **提升学生学习能力**
   通过诊断、练习、错题复盘、间隔复习和学习反馈，帮助学生持续补强薄弱点。
2. **扩大题型与练习接触面**
   让学生接触不同题型、难度层级和解题方式，减少因训练机会不足造成的考试不适应。
3. **支持教师观察与教学判断**
   教师可以查看班级概览、作业情况、学生进展、薄弱知识点和学生详情，辅助教学决策。
4. **支持家校协同**
   家长可以理解学生学习状态、进展和需要支持的方向，而不是只看到单一分数。
5. **连接社会志愿资源**
   平台可以连接志愿者、志愿机构、志愿企业、志愿老师和志愿学校，为学生提供行业认知、学习陪伴、职业分享、专业介绍和成长建议。
6. **提供真实职业与行业认知**
   学生有机会认识不同行业的人，了解真实工作环境、职业路径和行业要求，在选择学校、专业和未来方向时获得更真实的参考。
7. **帮助企业和社会更早发现潜力学生**
   在 AI 改变时代的背景下，系统可以在合规、安全、公平的前提下，帮助企业或机构更早认识有潜力的学生，并提供培养、指导或实践机会。
8. **服务国家人才培养**
   系统最终目标不是单点补习，而是通过学习能力、机会公平、行业认知和人才发现机制，提升整体学生群体水平。

**六、达成要求**

系统要被认为达到目标，至少需要满足以下要求：

1. **学习功能可用**
   - 学生可以完成注册/登录、学习检查、诊断、练习、错题复盘和学习反馈。
   - 学习内容必须包含多样题型和不同难度层级。
2. **自适应能力可验证**
   - BKT、IRT、评分、诊断策略、题目选择、间隔复习等算法必须有测试覆盖。
   - 算法行为不能只靠描述，必须有自动化证据。
3. **教师端闭环可用**
   - 教师能查看班级、作业、学生详情、学习指标和薄弱点。
   - 教师端核心路径必须有 e2e 回归覆盖。
4. **家校沟通可解释**
   - 家长和学校看到的学生状态应清晰、可解释，不制造焦虑或羞辱。
   - 反馈重点应是成长、支持和下一步行动。
5. **志愿资源接入可治理**
   - 志愿者、企业、机构、老师、学校的接入必须可审核、可记录、可追踪。
   - 涉及学生接触、导师指导、职业体验时，必须有学生保护、家长/学校授权和安全边界。
6. **公平性要求**
   - 系统不得按地域、贫富或学校资源对学生做负面标签。
   - 推荐、题型、机会分配和志愿资源匹配应尽量避免扩大原有差距。
7. **验收证据完整**
   - 必须保留自动化测试、功能验证、UX 评分、QA 签署和 loop log。
   - 不允许无证据签署，也不允许测试超时或失败后标记为 PASS。
8. **边界清晰**
   - 当前不包含生产部署、真实生产数据、云凭证、schema/migration、assignment CRUD 或未经批准的新架构。
   - 所有新功能必须通过 Milestone / Program / Work Order 拆解后执行。

**七、下一阶段建议方向**

M49 已完成教师端阶段性回归，下一阶段建议进入 M50 规划，重点可以放在：

1. 学生学习数据与教师观察之间的闭环对齐。
2. 家长/学校视角的最小可用信息展示。
3. 志愿者与志愿机构接入模型设计，但先做规则、边界和流程，不急于实现大功能。
4. 全系统目标文档统一，修正仍残留旧 Milestone 状态的文档不一致问题。

**八、初稿结论**

EduCore 的目标应从“自适应学习 MVP”升级为“平等学习与成长生态平台”。它通过学习训练、教师观察、家校协同和社会志愿资源连接，让学生获得更多题型、更多练习、更多真实世界认知和更多发展机会。系统坚持一视同仁，不制造特殊标签，最终目标是提升整体教育水平，并为国家培养更多有能力、有见识、有适应力的人才。
