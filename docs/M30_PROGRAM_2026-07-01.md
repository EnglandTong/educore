## 1. Program Goal

Deliver a read-only teacher assignments list API and surface assigned students on the Assignment Overview page, completing the product slice deferred since M27.

## 1a. Milestone Goal

**M30 primary goal:** Deliver `GET /api/v1/teacher/assignments` (read-only list of assigned students) and integrate an Assigned Students section into the existing Assignment Overview page — without schema changes, assignment CRUD, or new subsystems.

**Why this milestone exists:** M27–M29 built and hardened the overview using aggregate class data only. M30 closes the long-deferred QA follow-up for a dedicated assignments list endpoint and makes individual student assignments visible in the UI.

## 2. Program Scope

- Audit `TeacherAssignment` model and existing teacher API/frontend patterns.
- Implement `getTeacherAssignments` in `teacher.service.ts` and route in `teacher.routes.ts`.
- Add `fetchTeacherAssignments`, React Query hook, and Assigned Students table/card section on `AssignmentOverviewPage`.
- Update e2e mock; run typecheck/build and e2e; produce handoff.

## 3. Non-Goals

- No CRUD on assignments beyond read list.
- No schema/migration changes.
- No new subsystems or shared layers.
- No `packages/algorithms/` or `modules/` changes.
- No production deployment.
