## 1. Program Goal

Add Playwright smoke coverage for the Teacher Assignment Overview page delivered in M27 and hardened in M28, using existing e2e mock infrastructure.

## 2. Program Scope

- Audit teacher e2e specs and mock handlers.
- Provide realistic mocked class overview data for assignment overview page rendering.
- Add Playwright test(s) for sidebar or direct navigation to `/teacher/assignments` with content assertions.
- Run e2e suite (or targeted spec) and produce consolidated handoff.

## 3. Non-Goals

- No backend/API/schema changes.
- No product feature expansion beyond test coverage.
- No new shared test utilities layer unless inline in existing e2e files.
- No modifications to `apps/web/src/` product pages unless a minimal `data-testid` is strictly required (prefer role/text selectors first).
- No production deployment.
- No CI/CD pipeline changes.

| 1 | P29-01 | Lite | Audit teacher e2e mocks and Assignment Overview page selectors | none |

## 5. Dependency Rules

- P29-01 must complete before P29-02.
- P29-02 must complete before P29-03.
- P29-03 must complete before P29-04.

Developer may auto-advance when:

- Prior Work Order verification passed with evidence.
- No Stop Rule triggered.
- Changes stayed within Allowed Files.
- Fewer than three consecutive failures of the same verification command.

Developer must stop when:

- E2E failures require fixes outside Allowed Files.
- Playwright/browser setup requires system-level installation.
- Any STOP_RULES item triggers.
- Three consecutive failures of the same verification command for the same unresolved reason.

## 6. Complexity Definitions

- **Standard**: Mock enhancement or Playwright test implementation with verification.
- **Deep**: Not used in this Program.
